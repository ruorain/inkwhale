# ESP32-S3 桌摆适配

> V0.1 · 2026-10-26 18:10 · raw

## 想法

把云笔记的一小块能力做到桌面上，当摆件用。

## 能做什么

- 小屏循环显示最近几条 `#raw`，或者今天的回顾
- 按键开始录音，说完自动转文字进仓库
- 有新笔记时亮一下

## 为什么值得

手机解决「随时记」，摆件解决「抬头就能看见」。两件事不冲突。

`#raw` 的想法躺久了就忘了，桌面上摆着反而会一直提醒。

## 技术上要注意

- ESP32-S3 走 HTTPS 打 GitHub Contents API，和 app 用同一套接口
- 设备上不能存长期 token：改成分发只读/一次性 token，或者走一个极简中转
- 屏幕小，一次只能显示 5-8 行，排版要做极简
- 语音识别在设备上做不了，得录音传上去转，或者只做「按一下记一条」，内容回手机上补

## 优先级

排在主线之后（批次 6）。先把「写进去就真的在」修好，再谈多一块屏。
