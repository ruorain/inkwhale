## ISSUE-001 本地优先写入 + 失败队列

**问题**
保存走的是同步 GitHub API。弱网、切后台、锁屏都会失败，失败后内容直接丢——用户以为存了，其实没有。

**现状**
`EditorActivity.commit()` 直接 `GitHubApi.writeFile`，失败只弹一个横幅，草稿存在 SharedPreferences 里但没有统一队列，也不会自动重试。

**要做**
1. 保存时先写本地存储（现在已有 `Store.saveDraft`，但只存在内存旁路，未作为唯一真源）
2. 主写入路径改为「本地先落盘 → 立即返回成功」
3. 后台队列按顺序推送，失败退避重试（30s / 2min / 10min）
4. 列表和编辑器上显示同步状态：待同步（点）/ 已同步 / 失败（提示点击重试）
5. 队列要跨进程持久（app 被杀掉后重启仍能恢复）

**验收**
- 飞行模式下写一篇，关掉 app，开网后重新打开 → 内容自动推上去
- 弱网时保存，界面立刻返回，状态显示「待同步」
- 推失败三次后状态变「失败」，点一下能手动重试

**依赖** 无

## ISSUE-002 对话历史落仓库

**问题**
AI 对话页退出就清空。同上，聊了半小时的东西没了。

**现状**
`ChatActivity` 的 `history` 是内存 List，`onDestroy` 后消失。

**要做**
1. 对话按天归档到 `Deepseek/对话/YYYY-MM-DD.md`
2. 格式：每次发言一个小节，带时间戳；AI 回答保留原文
3. 会话结束（返回键 / 切后台超过 N 分钟）时写入
4. 进入对话页时，如果当天已有记录就接着写，而不是新建
5. 退出前弹一次确认：「保存这段对话？」（可记住选择）

**验收**
- 聊两轮后返回，仓库里出现 `Deepseek/对话/2026-10-26.md`
- 再进对话页，能看到刚才的对话历史

**依赖** ISSUE-001（复用同一套写入队列）

## ISSUE-003 最近打开三个

**问题**
首页副标题写「想从什么项目开始？」，但下面列的是「最新想法」，语义对不上。

**现状**
`MainActivity.renderHome()` 按路径顺序取前 5 篇，不反映「最近打开过什么」。

**要做**
1. 记录每次打开文件的时间（`Store` 里存 path → timestamp）
2. 首页改叫「最近打开」，取时间最新的 3 篇
3. 没打开记录时，回退成「最新想法」（按路径倒序）
4. 点击进入编辑器后更新时间戳

**验收**
- 打开 A、B、C 三篇后回首页，顺序是 C、B、A
- 全新安装、没打开过任何文件时，首页显示最新 3 篇而不是空白

**依赖** 无
