# 离线优先的本地知识库

## 背景

手机上的笔记应用几乎都要求联网。地铁里没信号，
灵感只能记在备忘录里，回头再手动搬一遍。

## 目标

- 本地写入零等待
- 联网后自动合并
- 冲突时不丢数据

## 实现路径

1. 用 SQLite 存草稿
2. 队列化推送
3. 版本号作为乐观锁

> 关键点：冲突不是错误，
> 是一个需要用户决策的状态。

```kotlin
fun push(draft: Draft): Result {
  val r = api.get(draft.path)
  if (r.sha == draft.baseSha) {
    api.put(draft.path, draft.body)
  } else {
    Result.Conflict(r)
  }
}
```

| 场景 | 处理 |
| --- | --- |
| sha 一致 | 直接写入 |
| sha 不一致 | 提示用户 |
| 网络失败 | 入队重试 |

- [x] 本地存储
- [x] 推送队列
- [ ] 自动合并
